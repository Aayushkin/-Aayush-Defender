Download Linux Version

Instructions:

# To use Aayush-Defender on Linux:
1. Download the ZIP file.
2. Extract the contents.
3. Open a terminal in the extracted folder.
4. Run the script with the following commands:
    chmod +x aayush-defender.sh
    sudo ./aayush-defender.sh

Windows Version

For Windows users, download the Aayush-Defender tool and run the PowerShell script to enhance your system's defense.

Download Windows Version

Instructions:

# To use Aayush-Defender on Windows:
1. Download the ZIP file.
2. Extract the contents.
3. Open PowerShell as Administrator.
4. Run the script with the following commands:
    Set-ExecutionPolicy RemoteSigned -Scope Process
    .\Aayush-Defender.ps1
